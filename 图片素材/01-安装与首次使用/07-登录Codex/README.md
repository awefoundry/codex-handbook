## 仍需补拍

- 浏览器完成授权后返回 App、CLI 或 IDE 的成功状态。
- App 或 IDE 的账号菜单、工作区检查和退出入口。
- CLI 的 `codex login status` 成功输出（只保留终端，不保留桌面和本地路径）。

发布前重新打开来源页面确认按钮文案，并逐张检查是否带出个人信息。
