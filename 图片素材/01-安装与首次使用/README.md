# 安装与首次使用图片规划

这个目录存放 `01-安装与首次使用` 栏目的官方图片和真实操作截图。

正式文章开始前，先确定截图分镜；真实操作完成并脱敏后，再把最终图片加入公开仓库。原始截图保存在私人工作台，不直接提交。

## 三批截图

### Codex App

一次完整操作建议覆盖：官方下载入口、下载完成、应用安装、首次启动、登录、选择 Codex、打开文件夹、权限模式、任务输入、修改结果、Changes 和完成状态。

### Codex CLI

一次完整操作建议覆盖：官方安装说明、终端环境、安装命令、版本输出、登录、进入项目目录、启动 Codex、权限请求和任务结果。

### IDE

一次完整操作建议覆盖：官方扩展入口、扩展安装、Codex 侧栏、登录、打开项目、添加文件上下文、任务输入、修改和 Review。

## 文件命名

每篇文章使用独立图片目录，文件按操作顺序编号，例如：

```text
图片素材/01-安装与首次使用/02-macOS安装Codex-App/
├── 01-官方下载入口.png
├── 02-安装包下载完成.png
├── 03-应用安装完成.png
├── 04-首次启动.png
├── 05-登录入口.png
└── 06-Codex模式可用.png
```

## 发布要求

- 一张图片只解释一个主要动作。
- 入口图保留页面或窗口上下文，关键控件可以适度裁切。
- 标注统一使用一种颜色和样式。
- Token、邮箱、本地用户名、私有路径和客户信息必须脱敏。
- 官方图片注明来源页面和链接。
- 实操图片必须来自真实操作，不使用 AI 图代替界面和结果。
