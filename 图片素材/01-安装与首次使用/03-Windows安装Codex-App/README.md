## 截图前检查

- 隐藏邮箱、头像、用户名、验证码和其他账号信息。
- 隐藏本地用户目录、私人项目名、客户数据和通知内容。
- 保留足够的窗口或页面上下文，让读者知道当前操作位置。
- 一张图只突出一个主要动作，不要过度裁切。
- 不在原始截图上覆盖无法还原的大面积装饰；标注版与原图分开保存。
