# 图片素材

知识库图片统一存放在这里，并与文章目录保持对应。

## 推荐结构

```text
图片素材/
└── 01-安装与首次使用/
    └── 02-macOS安装Codex/
        ├── 01-官方下载页面.png
        ├── 02-安装完成.png
        └── 03-首次运行.png
```

## 图片规范

- 使用“序号-图片内容”命名，不使用“截图1”“最终版2”。
- 关键实操至少包含入口、操作和结果截图。
- 报错文章保留报错状态和修复后的结果。
- Token、邮箱、本地用户名、私有路径和客户信息必须脱敏。
- 官方截图注明来源页面和链接。
- AI 概念图不能冒充真实产品界面或运行结果。

## 配图选择顺序

1. 正文涉及官方界面、功能说明或产品入口时，优先获取官方真实截图。
2. 正文依赖操作过程和运行结果时，由维护者按照文章提供的步骤亲自实操并截图。
3. 只有抽象概念确实需要视觉化、且没有合适官方图或实操图时，才考虑 AI 生图。
4. 图片无法增加解释力时，不配图。不要为了让文章显得丰富而加入无关装饰图。

需要 AI 生图时，文章任务应同时提供生成提示词、画面用途、构图要求、需要避免的元素和建议尺寸。最终图片由维护者生成并确认符合文意后加入仓库。
