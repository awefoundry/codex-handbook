# 图片素材

知识库图片统一存放在这里，并与文章目录保持对应。

## 推荐结构

```text
图片素材/
└── 01-安装与首次使用/
    └── 02-macOS安装Codex/
        ├── 01-官方下载页面.png
        ├── 02-安装完成.png
        └── 03-首次运行.png
```

## 图片规范

- 使用“序号-图片内容”命名，不使用“截图1”“最终版2”。
- 关键实操至少包含入口、操作和结果截图。
- 报错文章保留报错状态和修复后的结果。
- Token、邮箱、本地用户名、私有路径和客户信息必须脱敏。
- 官方截图注明页面链接和截图日期。
- AI 概念图不能冒充真实产品界面或运行结果。
