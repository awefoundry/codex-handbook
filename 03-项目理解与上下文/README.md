# 项目理解与上下文

让 Codex 在动手修改前先理解项目结构、约束和现有实现。

## 内容范围

- 识别项目入口、技术栈、依赖和运行方式。
- 阅读 README、配置文件、测试和错误日志。
- 使用 AGENTS.md 保存项目级规则。
- 控制上下文范围，避免一次加载无关内容。
- 处理大型仓库、多模块项目和历史代码。

这个栏目是从“会提问”进入“会在真实代码库中工作”的过渡。
