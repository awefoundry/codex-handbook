# 需要作者亲自截图

以下截图都应在一次性测试项目或脱敏副本中完成。截图只证明一个 UI 事实，不能包含真实凭据、客户数据、生产地址或可复用的登录信息。

- [ ] `01-permission-mode-selector.png`：起始位置为 Codex CLI/桌面端权限设置；菜单路径为“权限/Permissions → 审批或沙箱模式”；预期画面显示当前模式与可选模式，证明权限不是单一的“开/关”；隐藏账号、组织名、工作区路径和令牌；停在确认/应用前。
- [ ] `02-approval-prompt-before-command.png`：起始位置为隔离测试仓库；菜单路径为“新建任务 → 输入会修改文件或访问网络的模拟命令”；预期画面显示命令、目标范围和批准提示，证明高风险动作有人工检查点；隐藏真实路径、密钥、客户数据；停在批准按钮前。
- [ ] `03-git-diff-review.png`：起始位置为测试分支终端；菜单路径为终端运行 `git diff --stat`，再运行 `git diff`；预期画面显示变更文件范围和关键差异，证明测试通过前仍需看差异；隐藏私人路径和仓库远端地址；停在人工复核阶段。
- [ ] `04-focused-test-result.png`：起始位置为测试仓库；菜单路径为运行与改动对应的最小测试命令；预期画面显示实际命令、通过/失败结果和未运行项；使用模拟数据；停在测试结果，不执行发布、合并或生产操作。
- [ ] `05-risk-checklist.png`：起始位置为文章草稿或本地 Markdown；菜单路径为打开“低/中/高风险任务判断表”；预期画面显示资产、可回退性、可验证性、影响范围四个判断维度；隐藏文章外的私人内容；停在清单展示完成处。
- [ ] `06-policy-warning-new-session.png`：起始位置为脱敏测试会话；菜单路径为记录一次真实出现的政策提示后停止提交，再点击新建会话；预期画面显示错误提示与空白新会话，证明“停下来、换新会话”是止损动作而不是继续试探；隐藏账号、邮箱、网络信息和支持工单；不要故意提交违规内容。
- [ ] `07-delete-target-review.png`：起始位置为可丢弃测试仓库；菜单路径为展示删除命令、完整目标路径、Git/备份状态；预期画面证明删除前先核对目标且停在执行前；只使用模拟目录，禁止触碰用户目录、真实项目或生产数据。

不要截图登录二维码、验证码、Cookie、API Key、AppSecret、管理员身份、手机号、邮箱、付款信息、预览收件人或读者记录。
