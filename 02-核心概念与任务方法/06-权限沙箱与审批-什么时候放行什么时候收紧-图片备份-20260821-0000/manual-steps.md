# 需要作者亲自截图

官方文档截图已经覆盖概念、沙箱边界、权限档位、自动审阅和网络访问。为减少操作量，作者只需补 1 张本机审批截图；拒绝结果可引用现有第三方视频帧，其他动作写入实测记录即可。截图请只在可丢弃测试仓库中完成，统一隐藏用户名、主目录、仓库远端、任务正文中的私人信息、Cookie、Token、密钥和账号标识。

1. [ ] `manual/01-read-only-write-approval.png`：打开 Codex Desktop → 选择可丢弃测试仓库 → 保持只读模式 → 请求“新建 `sandbox-demo.txt`，内容写 test”；画面应显示写入动作需要审批及完整目标路径。确认路径只指向测试仓库，隐藏用户目录、任务名和账号信息；停在批准或拒绝按钮出现后，不要批准。

## 无需截图的记录

- 权限菜单位置：使用正文图一的官方文档说明，并在实测笔记中记录当前版本菜单名称。
- 拒绝后的替代方案：使用已有 `03-youtube-declined-approval-result.png` 作为第三方证据，同时在实测笔记中写明本机是否给出替代建议。
- 工作区内成功写入、网络访问和工作区外路径：只记录命令、目标路径、审批结果和回退方式，不新增截图。
