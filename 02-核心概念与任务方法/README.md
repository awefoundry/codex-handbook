# 核心概念与任务方法

这个栏目讲清楚怎样与 Codex 协作，而不是收集所谓“万能提示词”。

## 内容范围

- 任务、上下文、工具、权限和完成标准。
- 如何描述目标、限制范围和提供必要资料。
- 分析、计划、执行和验证分别适合什么时候使用。
- 如何拆分复杂任务、纠正方向和管理长任务。
- 常见沟通失败及改进方法。

重点是可复用的做事方法，并通过真实任务说明为什么这样写更有效。
