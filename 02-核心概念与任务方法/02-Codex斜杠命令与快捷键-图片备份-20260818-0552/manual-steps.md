以下截图用于证明当前机器上的实际入口。请使用无敏感内容的测试会话；不要为了截图执行审查、发布、删除或其他有副作用的命令。

- [ ] `01-Codex-Desktop斜杠命令菜单.png`：打开 Codex Desktop 的普通本地会话 → 点击输入框 → 输入 `/`；保留菜单和应用标题；隐藏项目路径、会话标题和账号信息；停在菜单展开状态，不执行命令。
- [ ] `02-Codex-Desktop键盘快捷键设置.png`：`设置 > 键盘快捷键` → 搜索 `Codex`；展示搜索框和当前绑定；隐藏账号信息；停在设置页，不修改绑定。
- [ ] `03-Codex-CLI斜杠命令菜单.png`：在临时空目录运行 `codex` → 输入 `/`；展示 CLI 当前菜单；不要使用私有仓库或真实项目路径；停在菜单展开状态，不执行命令。
- [ ] `04-Codex-IDE斜杠命令菜单.png`：打开公开或临时测试项目 → 在 Codex 输入框输入 `/`；展示 IDE 菜单；隐藏远端 URL、用户名和私有文件名；停在菜单展开状态。

若某入口在当前版本没有这些命令，保留截图并在登记表说明“当前版本未提供”，不要用旧教程截图替代。
