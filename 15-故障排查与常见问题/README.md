# 故障排查与常见问题

按照“现象、原因、检查、处理、验证”的结构记录问题，方便读者快速定位。

## 内容范围

- 安装和登录失败。
- 模型不可用或用量限制。
- 文件、目录和沙箱权限问题。
- 命令执行、依赖安装和构建失败。
- 网络、搜索、MCP 和 OAuth 问题。
- 上下文丢失、任务中断和结果偏离。
- Git 冲突、脏工作区和误修改处理。

## 首期练习的直接排查

这些问题对应[首次任务：修改本地网页并检查结果](../00-从这里开始/07-完成第一个真实任务.md)和[结果检查文章](../01-安装与首次使用/09-完成第一次修改并检查结果.md)。

| 现象 | 先检查 | 下一步 |
|---|---|---|
| Codex 说找不到 `index.html` | App/CLI 当前打开的目录是否直接包含 `index.html` 和 `styles.css` | 从练习包重新复制 `起始文件/` 到新目录，再打开复制出的目录 |
| 标题改了，但按钮链接或 CSS 也变了 | 查看 diff，比较 `styles.css` 与 starter，并核对 `https://example.com` | 停止继续编辑，重新解压到新目录；不要清空真实工作区或执行破坏性 Git 重置 |
| 页面能打开，但看起来不像原页面 | 浏览器中打开的是当前测试目录的 `index.html`，还是其他同名文件 | 从文件管理器或终端确认完整路径，再重新打开当前文件 |
| 登录成功但不能读取练习文件 | 当前客户端是否打开了复制出的目录，以及是否出现读取/编辑审批 | 回到[登录 Codex](../01-安装与首次使用/07-登录Codex.md)和[打开第一个本地项目](../01-安装与首次使用/08-打开第一个本地项目.md)，记录客户端、系统和完整错误 |

本表只覆盖首期练习已有的检查路径。没有完整复现材料的问题，不在这里写成已经修复；请保留错误原文和实际环境，便于后续补充。
