# Codex 中文教程与实战知识库

面向中文读者的 Codex 从入门到实战知识库，覆盖 Codex App、CLI、IDE、项目理解、代码修改、Git 协作、测试调试、Skills、插件、MCP、权限安全和自动化工作流。

这里整理的是可以继续核对和复现的内容：教程正文、真实操作截图、配置示例、官方资料、社区项目记录和故障排查过程。项目由独立维护者维护，不代表 OpenAI 官方，也不构成对第三方工具的推荐或保证。

本仓库不需要安装依赖。可以直接在 GitHub 上阅读；如果需要本地检索或离线查看，再克隆仓库即可：

```bash
git clone https://github.com/awefoundry/codex-handbook.git
cd codex-handbook
```

从 [07-Skills 实战](./07-Skills实战/) 开始，继续阅读 [08-插件工作流](./08-插件工作流/)、[09-MCP 与外部工具](./09-MCP与外部工具/)、[10-配置模型与权限安全](./10-配置模型与权限安全/) 和 [11-自动化与高级工作流](./11-自动化与高级工作流/)。

## 内容标准

- 官方功能优先引用 OpenAI 官方文档，并注明链接、适用范围和版本信息。
- 社区项目会标注为第三方项目，并链接原始仓库或官方说明。
- 实操文章尽量使用真实环境中的截图、命令和运行结果，不用生成界面冒充实测。
- 未亲自验证的步骤会标注为待验证、计划内容或个人判断，不把推测写成结论。
- 一篇文章尽量回答：适合谁、解决什么问题、需要什么前置条件、怎样操作、如何验证、哪里容易出错。

## 内容状态与时效

仓库会持续补充新章节。目录中的文章可能处于正式发布、待实操、待编写或资料整理阶段，具体状态以文章标题、章节 README 和更新日志为准。在线站点只展示已经通过整理和发布检查的内容。

Codex 的界面、模型、权限设置和命令会随版本变化。阅读教程时，优先关注文章标注的操作系统、软件版本、测试日期和官方来源；遇到不一致的地方，请把实际版本和报错信息一起提交到 Issue。

## 如何反馈和贡献

发现错误时，请尽量提供：

1. 文章路径或网站页面。
2. 你的系统、Codex 入口和相关版本。
3. 可以复现的步骤、实际结果和期望结果。
4. 相关截图或官方资料链接，注意删除 Token、邮箱、用户名和私有路径。

提交文章、截图或修订前，请先阅读 [贡献指南](./贡献指南.md) 和 [版权与引用说明](./版权与引用说明.md)。贡献内容应保持范围清楚，外部链接要服务于当前问题，不要在无关 Issue、Discussion 或 PR 中重复发布推广链接。

## 如果你是从外部文章来到这里

GitHub 仓库适合核对源文件和完整材料。如果你更关心阅读体验，可以直接进入 [CodexGuide 在线教程](https://codexguide.io/)，从 [学习路线](https://codexguide.io/paths) 选择起点，或从 [快速上手](https://codexguide.io/quickstarts) 完成一次小任务，再回到对应章节查看原始材料。

网站上的文章会提供相关文章、案例和排障入口；仓库中的相对链接则保留源内容之间的完整关系。根据自己的阅读目的选择入口即可。
