# Codex 中文知识库

一个面向中文读者的 Codex 从 0 到 1 学习与实战知识库。

这里不只整理官方文档，也会结合真实操作、项目案例、社区工具和踩坑记录。目标是让不同基础的读者都能找到入口，并且能够照着文章完成操作、验证结果。

## 从哪里开始

- 第一次了解 Codex：从 [00-从这里开始](./00-从这里开始/) 阅读。
- 准备安装和第一次使用：进入 [01-安装与首次使用](./01-安装与首次使用/)。
- 想按自己的基础学习：查看 [学习路线.md](./学习路线.md)。
- 想快速找到某一类内容：查看 [内容地图.md](./内容地图.md)。
- 遇到报错或权限问题：进入 [15-故障排查与常见问题](./15-故障排查与常见问题/)。

## 内容原则

- 官方内容以 OpenAI 官方文档为主要依据，并保留来源链接、适用范围和必要的版本说明。
- 社区项目必须明确标注为第三方项目，不写成官方功能。
- 实操文章优先使用真实截图、配置和运行结果，不使用 AI 生成的假界面。
- 没有亲自验证的步骤会明确标注，不把推测写成结论。
- 每篇文章尽量回答：适合谁、解决什么问题、如何操作、怎样验证、哪里容易出错。
