# 任务说明：修复缺失金额并补回归测试

## 目标

只修改练习副本中的金额格式化函数和直接测试，完成下面四个约定：

- `12.5` 仍输出 `¥12.50`；
- `0` 仍输出 `¥0.00`；
- 订单缺少 `amount`，格式化函数收到 `undefined` 时输出 `--`；
- 不改变订单顺序、`demo.mjs` 的输入结构和正常金额格式。

## 操作顺序

1. 先运行 `test/formatAmount.test.mjs`，再运行 `node demo.mjs`。
2. 只读查看 `demo.mjs`、`src/formatAmount.mjs` 和测试文件，追踪 `amount` 从订单对象到格式化函数的路径。
3. 在测试文件中增加缺失值断言，保持实现不变，重新运行同一测试并确认它因为断言失败而退出非零。
4. 只在 `src/formatAmount.mjs` 增加缺失值分支，保留原有数字格式化逻辑。
5. 用同一条测试命令和 `node demo.mjs` 检查结果，再查看差异。

## 范围

本练习不处理 `null`、空字符串、非数字文本、无限值、币种转换或精度策略。它们需要单独的产品约定和测试，不能顺手扩展成另一项重构。
