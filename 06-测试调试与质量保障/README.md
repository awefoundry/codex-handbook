# 测试调试与质量保障

代码能生成不等于任务完成。本栏目关注如何证明修改有效，并降低回归风险。

## 内容范围

- 读取报错、日志和调用栈。
- 复现问题并定位原因。
- 单元测试、集成测试和端到端测试。
- Lint、类型检查、构建和回归验证。
- 使用浏览器和开发者工具检查前端效果。
- 识别不稳定测试和缺失测试。
