# Codex CLI 斜杠命令与快捷键（0.165.0 更新）：按用途分组速查，任务运行中哪些能用

> 本文在线版：[codexguide.io/guides/codex-cli-slash-commands](https://codexguide.io/guides/codex-cli-slash-commands)

> 核对依据：OpenAI 官方文档 [Developer commands](https://learn.chatgpt.com/docs/developer-commands) 的 CLI 和 IDE 两部分；「任务运行中能不能用」「侧边对话里能不能用」「在哪些系统上显示」来自 Codex 源码 [`codex-rs/tui/src/slash_command.rs`（rust-v0.165.0）](https://github.com/openai/codex/blob/rust-v0.165.0/codex-rs/tui/src/slash_command.rs)。核对日期 2026-10-29（北京时间）。命令会随版本变化，以你输入框里的候选菜单为准。
>
> 2026-10-29 改写说明：旧版只讲了十几个常用命令，这一版按官方命令表补全到 0.165.0，按用途分组，并补上任务运行中的可用性。

## 怎么用

- 在输入框里输入 `/`，弹出命令菜单；继续输入命令名可以过滤。
- 有些命令后面可以直接带参数，比如 `/clear release prep` 会在新开对话时顺便命名。
- **任务正在运行时**：输入命令后按 `Tab`，命令会排进下一轮。官方文档说明，排队的命令在执行时才解析，所以菜单和报错会在当前这轮结束后才出现；排队前补全仍然可用。
- 本文只讲 CLI。IDE 扩展的命令不一样，放在文末单独一节。

命令行里的子命令和启动参数（`codex exec`、`codex resume`、`--model` 等）不是斜杠命令，见[Codex CLI 命令速查](../16-图解与速查/01-Codex-CLI命令速查-子命令与启动参数.md)。

## 按用途分组速查

下表中「运行中」一列：✅ 表示任务进行中也能直接用；❌ 表示要等这轮结束（或者按 `Tab` 排队）。依据是 0.165.0 源码里的 `available_during_task`。

### 1. 模型、权限与审批

| 命令 | 作用 | 运行中 |
|---|---|---|
| `/model` | 切换模型，以及推理强度（如果有） | ✅ |
| `/fast` | 打开或关闭当前模型的 Fast 服务档位，只在模型目录提供时出现 | ✅ |
| `/permissions` | 调整 Codex 不问你就能做什么，比如在 Auto 和 Read Only 之间切换 | ✅ |
| `/approve` | 自动审查拒绝了某个操作时，批准重试一次 | ✅ |
| `/plan` | 切到计划模式，可以直接带上要求 | ❌ |
| `/goal` | 设置、修改、暂停、恢复、查看或清除任务目标 | ✅ |

`/goal` 的用法见[Codex Goal 模式](../11-自动化与高级工作流/05-Codex使用Goal模式运行长任务.md)。

### 2. 会话管理

| 命令 | 作用 | 运行中 |
|---|---|---|
| `/new` | 在同一个 CLI 里开始一条新对话 | ❌ |
| `/clear` | 清屏并开始一条新对话 | ❌ |
| `/resume` | 从会话列表里恢复之前的对话 | ✅ |
| `/fork` | 把当前对话分叉成一条新对话，原对话保留 | ❌ |
| `/side`（别名 `/btw`） | 开一个临时的侧边对话，不打扰主对话 | ✅ |
| `/rename` | 给当前对话改名 | ✅ |
| `/archive` | 归档当前会话，从列表里移走但不删记录 | ✅ |
| `/delete` | 永久删除当前会话及其分支会话 | ❌ |
| `/agents` | 打开 Agent 指挥中心，浏览对话、切换 Agent | ✅ |
| `/subagents` | 切换到某个子 Agent 的线程 | ✅ |
| `/app` | 把当前会话转到 ChatGPT 桌面端继续，只在 macOS 和 Windows 显示 | ✅ |
| `/quit`、`/exit` | 退出 CLI | ✅ |

多条对话怎么起名、恢复和交接，见[Codex CLI 管理多条任务线](../11-自动化与高级工作流/02-CodexCLI管理多条任务线.md)。

### 3. 上下文与对话内容

| 命令 | 作用 | 运行中 |
|---|---|---|
| `/status` | 显示模型、审批策略、可写目录和 token 用量，可以看剩余上下文 | ✅ |
| `/compact` | 用摘要替换前面的对话，腾出上下文 | ❌ |
| `/recap` | 生成当前对话的总结，不压缩上下文 | ❌ |
| `/mention` | 把某个文件或目录加进对话 | ✅ |
| `/ide` | 把 IDE 里打开的文件、选中内容等加进下一条消息 | ✅ |
| `/copy` | 复制 Codex 最近一条完整回复（也可以按 `Ctrl+O`） | ✅ |
| `/export` | 把对话导出成 Markdown，存文件或复制到剪贴板 | ❌ |
| `/memories` | 设置是否使用和生成记忆 | ❌ |

`/compact` 和 `/recap` 的区别、自动压缩的阈值，见[Codex 上下文窗口与压缩](../02-核心概念与任务方法/07-Codex上下文窗口与压缩-compact自动压缩与何时新开会话.md)。

### 4. 查看和审查改动

| 命令 | 作用 | 运行中 |
|---|---|---|
| `/diff` | 显示 Git 改动，包括还没被 Git 跟踪的文件 | ✅ |
| `/review` | 让 Codex 审查当前工作区的改动 | ❌ |
| `/init` | 在当前目录生成 `AGENTS.md` 骨架 | ❌ |

### 5. 扩展：Skills、插件、MCP、Hooks

| 命令 | 作用 | 运行中 |
|---|---|---|
| `/skills` | 浏览和使用 Skills | ✅ |
| `/plugins` | 浏览已安装和可安装的插件 | ✅ |
| `/apps` | 浏览应用（连接器），以 `$app-slug` 的形式插入消息 | ✅ |
| `/mcp` | 列出已配置的 MCP 工具，加 `verbose` 看服务器详情 | ✅ |
| `/hooks` | 查看和管理 Hooks，信任新的或改过的 Hook | ✅ |
| `/import` | 导入 Claude Code 或 Cursor 的配置、项目和对话 | ❌ |

### 6. 后台终端与工作目录

| 命令 | 作用 | 运行中 |
|---|---|---|
| `/ps` | 查看后台终端和它们最近的输出 | ✅ |
| `/stop`（别名 `/clean`） | 停止当前会话启动的所有后台终端 | ✅ |
| `/cd` | 切换会话的工作目录（主对话空闲时） | ❌ |
| `/pwd`、`/cwd` | 显示当前工作目录 | ✅ |
| `/worktree` | 在受管理的 Git worktree 里开始或继续对话 | ❌ |
| `/daemon` | 打开后台服务的控制界面 | ✅ |

### 7. 用量、诊断与反馈

| 命令 | 作用 | 运行中 |
|---|---|---|
| `/usage` | 查看账号 token 用量（按日、周或累计），或使用一次额度重置 | ✅ |
| `/debug-config` | 打印配置分层和要求的诊断信息 | ✅ |
| `/warnings` | 查看会话中出现过的警告和诊断 | ✅ |
| `/feedback` | 把日志发给 Codex 维护者 | ✅ |
| `/logout` | 退出登录，清除本机凭证 | ❌ |

### 8. 界面与输入

| 命令 | 作用 | 运行中 |
|---|---|---|
| `/statusline` | 选择和排列底部状态栏显示的内容 | ✅ |
| `/title` | 选择终端窗口或标签页标题显示的内容 | ✅ |
| `/theme` | 选择语法高亮主题 | ❌ |
| `/pets`、`/pet` | 选择或隐藏终端宠物 | ❌ |
| `/tui` | 选择下次启动时的终端模式（保留滚动记录或全屏） | ❌ |
| `/raw` | 切换原始滚动模式，方便选中复制长输出 | ✅ |
| `/keymap` | 重新映射快捷键，保存到 `config.toml` | ❌ |
| `/vim` | 打开或关闭输入框的 Vim 模式 | ❌ |

### 9. 实验功能与系统设置

| 命令 | 作用 | 运行中 |
|---|---|---|
| `/experimental` | 开关实验功能，比如网络代理、运行时防止休眠 | ❌ |
| `/setup-default-sandbox` | 设置提权的 Windows 沙箱（仅 Windows） | ❌ |

### 源码里有、官方命令表暂未列出的

0.165.0 源码里还有几个命令，官方命令表当前没有列出：`/config`（Codex 偏好设置）、`/presets`（运行或保存可复用的提示词和斜杠命令）、`/daybreak`（开关 Daybreak）、`/voice`（开始或停止语音）。它们是否出现在你的菜单里，可能和功能开关、账号或灰度有关，本文没有逐个验证。菜单里没有就是还没对你开放，不用去找。

## 侧边对话里能用哪些

用 `/side` 开的临时侧边对话，按 0.165.0 源码只允许下面这些命令：

`/copy`、`/agents`、`/export`、`/raw`、`/diff`、`/mention`、`/status`、`/daemon`、`/warnings`、`/pwd`、`/usage`、`/ide`

其他命令要回到主对话再用。

## 常用快捷键

以下来自官方文档的「Interactive shortcuts」：

| 按键 | 作用 |
|---|---|
| `@` | 搜索工作区文件，把路径加进消息 |
| `↑` / `↓` | 翻出之前的草稿 |
| `Ctrl+R` | 搜索历史消息，`Enter` 选用，`Esc` 取消 |
| `Ctrl+O` | 复制 Codex 最近一条完整回复（同 `/copy`） |
| 行首加 `!` | 按当前的审批和沙箱设置运行一条本地 shell 命令 |
| `Tab`（任务运行中） | 把消息、斜杠命令或 shell 命令排进下一轮 |
| `Enter`（任务运行中） | 把新指令插进当前这轮 |
| 输入框为空时按两次 `Esc` | 编辑上一条消息，并从那里分叉对话 |
| `Ctrl+C` | 关闭会话（同 `/exit`） |
| `Ctrl+L` | 只清空终端显示，对话不变；`/clear` 才会开新对话，两者在任务运行中都不能用 |

想改键用 `/keymap`。

## 命令找不到时

1. 看版本：`codex --version`。本文按 0.165.0 核对，老版本可能没有某些命令。
2. 更新到最新版，方法见[Codex 更新与卸载](./12-Codex更新与卸载.md)。
3. 有些命令有条件：`/fast` 要模型目录提供 Fast 档位，`/app` 只在 macOS 和 Windows 显示，`/setup-default-sandbox` 只在 Windows 有意义。
4. 输入了命令没反应，看看是不是任务正在运行，这时候属于 ❌ 的命令要排队或等这轮结束。

## IDE 扩展里的命令

VS Code、Cursor、Windsurf 里的 Codex 扩展有自己的斜杠命令，和 CLI 不同。官方文档列出的有：

| 命令 | 作用 |
|---|---|
| `/approve` | 自动审查启用时，批准重试一次被拒绝的操作 |
| `/cloud` | 在云端运行这个对话（云端执行可用时） |
| `/cloud-environment` | 选择这个对话的云端环境 |
| `/compact` | 压缩当前对话的上下文 |
| `/fast` | 开关 Fast 服务档位（可用时） |
| `/feedback` | 打开反馈窗口，可以附带日志 |
| `/fork` | 把本地对话复制成一条新的本地对话 |
| `/goal` | 设置一个让 Codex 持续追踪的目标 |
| `/ide-context` | 开关自动附带 IDE 上下文 |
| `/init` | 为当前项目生成 `AGENTS.md` 骨架 |
| `/local` | 在本地工作区运行这个对话 |
| `/mcp` | 打开 MCP 状态，查看已连接的服务器 |
| `/memories` | 设置对话是否使用或生成记忆（可用时） |
| `/model` | 选择当前对话的模型 |
| `/personality` | 选择回复风格（当前模型支持时） |
| `/plan` | 开关计划模式 |
| `/project` | 选择新对话所在的项目 |
| `/reasoning` | 选择当前对话的推理强度 |
| `/review` | 进入代码审查模式，审查未提交的改动或和基准分支对比 |
| `/side` | 开一个临时侧边对话，不打断主对话 |
| `/status` | 显示对话 ID、上下文用量和额度 |
| `/worktree` | 在新的 Git worktree 里运行这个对话 |

扩展还提供了可以绑定快捷键的编辑器命令（在编辑器的快捷键设置里搜 `Codex` 或命令 ID）：

| 命令 ID | 默认快捷键 | 作用 |
|---|---|---|
| `chatgpt.newChat` | macOS `Cmd+N`，Windows/Linux `Ctrl+N` | 新建对话 |
| `chatgpt.addToThread` | 无 | 把选中的代码加进当前对话 |
| `chatgpt.addFileToThread` | 无 | 把整个文件加进当前对话 |
| `chatgpt.newCodexPanel` | 无 | 新建一个 Codex 面板 |
| `chatgpt.openCommandMenu` | 无 | 打开 Codex 命令菜单 |
| `chatgpt.openSidebar` | 无 | 打开 Codex 侧边栏 |
