# Codex CLI 斜杠命令与快捷键使用指南

Codex CLI 的斜杠命令用于管理当前会话。输入 `/` 可以查看本机版本实际提供的命令，再选择模型、检查权限、压缩上下文或审查改动。这类操作不会变成普通提示词发送给模型，而是由 CLI 直接处理。

本文只介绍 Codex CLI。Codex App、IDE 扩展和其他入口的命令集合可能不同，不应照搬这里的列表。命令会随版本更新，使用前请以输入框中的候选菜单和 [OpenAI 官方开发者命令文档](https://learn.chatgpt.com/docs/developer-commands?surface=cli) 为准。

## 先分清三类操作

下面三种写法看起来相近，作用位置不同。

| 类型 | 示例 | 在哪里执行 |
|---|---|---|
| 会话斜杠命令 | `/status`、`/model` | Codex CLI 的输入框 |
| CLI 子命令 | `codex resume`、`codex review` | PowerShell、终端或 Shell |
| 键盘快捷键 | `Ctrl+L`、`Ctrl+O` | Codex CLI 交互界面 |

`/resume` 和 `codex resume` 都能继续旧会话，但入口不同。前者从当前 TUI 打开会话选择器，后者从系统终端启动恢复流程。遇到命令无效时，先确认它属于哪一类。

## 打开斜杠命令菜单

启动 Codex CLI 后，在输入框中键入 `/`。候选菜单会显示当前版本可用的命令。继续输入命令名可以缩小范围，选中后按 Enter 执行。

这一步也是最可靠的自查方式。官方文档可能覆盖较新的功能，本机安装的 CLI 版本、操作系统和当前会话状态仍会影响命令是否出现。

可以先运行下面两个检查。

```text
/status
/usage
```

`/status` 显示当前模型、审批策略、可写目录和上下文使用情况。`/usage` 用于查看账号的 Token 活动；没有对应服务账号认证时，CLI 会提示先登录。

## 调整模型和权限

### 使用 `/model` 切换模型

输入 `/model` 后，从弹出的列表中选择模型。CLI 会在会话中确认变更，再运行 `/status` 可以复核当前模型。

模型列表由账号权限和当前 CLI 获取到的模型目录决定。不要依赖旧文章中的固定名单。

### 使用 `/permissions` 调整执行边界

`/permissions` 打开审批预设选择器。只读调查可以选择 Read Only；需要修改工作区时，再选择允许当前任务执行的模式。

权限决定 Codex 可以执行哪些动作，不保证任务判断正确。扩大权限前仍要检查工作目录、Git 状态和任务范围。

## 管理长会话

### 使用 `/compact` 压缩上下文

长会话积累了大量历史内容时，输入 `/compact`。Codex 会先请求确认，再把较早的对话压缩成摘要，为后续工作释放上下文空间。

压缩前应确认关键文件路径、验证结果和未完成事项已经说清楚。摘要能保留主要信息，但不适合代替项目文档或 Git 记录。

### 使用 `/new` 和 `/clear` 开始新会话

`/new` 在同一个 CLI 进程中开始新会话，并保留当前终端画面。`/clear` 会清空可见终端，同时建立新会话。

`Ctrl+L` 只清理终端显示，不会新建会话。正在执行任务时，CLI 可能暂时禁用 `/clear` 和 `Ctrl+L`。

### 使用 `/resume` 和 `/fork` 继续工作

`/resume` 打开已保存会话列表，选择后恢复原来的对话记录。`/fork` 复制当前会话并生成新的会话 ID，适合在保留原路线的同时尝试另一种方案。

恢复旧会话后先运行 `/status`，再检查 Git 状态。会话记录可以恢复，工作区文件可能已经发生变化。

## 检查 Codex 改了什么

### 使用 `/diff` 查看改动

`/diff` 显示已暂存、未暂存和未跟踪的文件变化。任务进行到中间也可以查看，及时发现范围扩大或临时文件混入。

### 使用 `/review` 发起工作区审查

`/review` 让 Codex 审查当前工作树，重点寻找行为问题、风险和缺少的测试。它不会代替测试和构建。审查后仍需运行与项目匹配的验证命令。

### 使用 `/mention` 指定文件

输入 `/mention` 并选择路径，可以把文件明确加入当前对话。大型仓库中，这比笼统地要求 Codex 读取整个项目更容易控制上下文范围。

## 几个实用的界面操作

OpenAI 当前开发者命令文档列出了下面这些默认操作。

| 操作 | 默认入口 | 作用 |
|---|---|---|
| 清理终端显示 | `Ctrl+L` | 保留当前会话，只清空可见内容 |
| 复制最近一条完整回复 | `Ctrl+O` 或 `/copy` | 把最近完成的 Codex 输出复制到剪贴板 |
| 切换原始回滚显示 | `Alt+R` 或 `/raw` | 让终端选择和复制更直接 |
| 修改按键映射 | `/keymap` | 查看、修改并保存 TUI 快捷键 |

自定义快捷键写入 `tui.keymap`。不同终端可能拦截相同组合键，修改后要在当前终端实际验证。

## 命令找不到时怎样排查

先输入 `/` 查看候选菜单。如果命令没有出现，按下面顺序检查。

1. 运行 `codex --version`，确认实际执行的是哪一份 CLI。
2. 检查命令是否只在特定系统、认证方式或会话状态下提供。
3. 确认没有把 `codex review` 这类终端子命令输进会话输入框。
4. 对照官方开发者命令页，查看命令是否改名、受功能开关控制或要求升级。
5. 使用 `/debug-config` 检查配置层级和策略限制。

`/setup-default-sandbox` 只在 Windows 使用受限沙箱时出现。`/fast`、`/personality` 等命令也可能根据模型目录和功能支持情况隐藏。候选菜单没有显示时，不应假定本机一定支持。

## 常用命令速查

| 目标 | 命令 |
|---|---|
| 查看会话状态 | `/status` |
| 切换模型 | `/model` |
| 调整审批与权限 | `/permissions` |
| 压缩长会话上下文 | `/compact` |
| 查看工作区改动 | `/diff` |
| 审查当前工作树 | `/review` |
| 恢复旧会话 | `/resume` |
| 分叉当前会话 | `/fork` |
| 开始新会话 | `/new` |
| 明确引用文件 | `/mention` |
| 查看和修改快捷键 | `/keymap` |
| 退出 CLI | `/quit` 或 `/exit` |
