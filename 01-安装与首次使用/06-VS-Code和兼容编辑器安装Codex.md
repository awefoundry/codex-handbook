# VS Code 和兼容编辑器安装 Codex

> 本文按当前界面整理，按钮名称可能会随编辑器版本更新

Codex 可以直接作为编辑器扩展使用。下面先走一遍 VS Code 的安装和登录，再介绍 Cursor 的入口。不同版本的按钮位置会有变化，但核心步骤相同，先找到官方扩展(找准认证标志下载)，再打开 Codex 侧栏并完成登录。

## 先在 VS Code 中安装

打开 VS Code 的扩展市场（左侧边栏四个小方块），搜索 Codex。点击安装前，先核对扩展的发布者信息，避免误装名称相近的扩展。

![Codex 扩展详情页](image-8.png)
<p align="center">图二：Codex 扩展详情页。</p>

安装完成后，活动栏会出现 Codex 入口。点击它打开侧栏，第一次使用时需要先登录。

![打开 Codex 侧栏](image-9.png)
<p align="center">图三：打开 Codex 侧栏。</p>

如果侧栏没有出现登录入口，先检查当前网络能否打开登录页面。必要时更换网络节点，再重新打开侧栏或重启编辑器。扩展安装和账号登录是两个环节，安装成功不代表登录服务一定可达。

网络正常时，会看到登录界面，如下图所示。

![Codex 登录界面](image-10.png)
<p align="center">图四：Codex 登录界面。</p>

点击“通过 ChatGPT 登录”后，浏览器会打开网页端登录页面。完成账号登录和授权，再回到 VS Code，侧栏会刷新为已登录状态。

![通过 ChatGPT 登录 Codex](image-11.png)
<p align="center">图五：通过 ChatGPT 登录 Codex。</p>

如果浏览器没有自动切回编辑器，直接返回原来的 VS Code 窗口，重新查看侧栏状态。登录过程中尽量不要关闭浏览器或编辑器。

按照引导提示点击“下一步”完成首次设置，随后就能在当前编辑器中使用 Codex。

![完成首次设置](image-12.png)

## 打开项目并提供上下文

登录后，先在 VS Code 中打开项目文件夹，再打开需要处理的文件。这样选择上下文时能直接找到项目内的相关文件。使用前仍要检查文件权限，不要把密钥、令牌等敏感信息加入上下文。

![打开项目和添加文件上下文](image-13.png)
<p align="center">图七：打开项目和添加文件上下文。</p>

可以从左上角的文件菜单打开项目中的文件。

![从文件菜单打开文件](image-14.png)
<p align="center">图八：从文件菜单打开文件。</p>

打开文件后，在 Codex 侧栏中选择当前文件，或添加需要参考的其他文件，再描述要完成的任务。可以先让 Codex 解释一个函数或提出一处局部修改，确认响应正常后再处理更大的改动。

## 在 Cursor 中安装

Cursor 基于 VS Code 的编辑器框架，安装 Codex 的步骤与 VS Code 接近。扩展市场的入口会因版本和布局不同而变化，可能在左侧边栏，也可能在左侧上方的活动栏，下面截图展示的是后一种位置。

![Cursor 的扩展入口](image-20.png)
<p align="center">图九：Cursor 的扩展入口。</p>

打开扩展市场后搜索 Codex，点击安装。安装完成后，如果侧栏或活动栏没有立即显示 Codex，先切换到其他面板再切回；仍未出现时，重启 Cursor 让扩展重新加载。

![在 Cursor 中搜索 Codex](image-16.png)

![Cursor 中已安装的 Codex 扩展](image-17.png)

点击“通过 ChatGPT 登录”，按浏览器页面完成登录，再回到 Cursor。登录方式与 VS Code 相同，两个编辑器使用的是同一个 ChatGPT 账号。

## 常见问题

- **安装后找不到入口。** 先确认扩展确实安装完成，再检查活动栏是否被隐藏；重启编辑器通常可以触发重新加载。
- **没有显示登录页面。** 优先检查网络连接和当前节点。登录页面无法访问时，反复点击登录不会解决问题。
- **浏览器登录后编辑器仍未登录。** 回到原先打开扩展的编辑器窗口，等待几秒后重新打开 Codex 侧栏；必要时重启编辑器。
- **Codex 看不到项目文件。** 确认打开的是项目文件夹，并在请求中明确添加需要参考的文件或当前文件上下文。
