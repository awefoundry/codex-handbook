# VS Code 和兼容编辑器安装 Codex

> 本文按当前界面整理。编辑器更新后，按钮名称和位置可能会变化，请以你看到的实际界面为准。

Codex 可以直接安装到 VS Code、Cursor 等兼容编辑器中。安装完成后，打开 Codex 侧栏，完成登录，就可以在项目文件的上下文中使用它。

## 先说结论

- **VS Code**：从扩展市场搜索 Codex，核对发布者和认证标志后安装。
- **Cursor**：操作方式与 VS Code 接近，扩展市场的位置可能略有不同。
- **第一次使用**：安装后需要通过 ChatGPT 登录，并完成首次设置。
- **开始处理项目**：先打开项目文件夹，再把当前文件或其他参考文件加入上下文。

> **安全提醒**：密钥、令牌和其他敏感信息不要加入 Codex 上下文。安装扩展时，也要先核对官方发布者和认证标志。

## 一、在 VS Code 中安装 Codex

### 1. 打开扩展市场

打开 VS Code 的扩展市场。扩展图标通常在左侧边栏，图标是四个小方块。

搜索 `Codex` 后，先核对发布者，再点击“安装”。

![VS Code 扩展市场中的 Codex](image-7.png)
<p align="center">图 1｜VS Code 扩展市场中的 Codex</p>

### 2. 查看扩展详情

点击搜索结果，进入 Codex 扩展详情页，再确认发布者和认证标志。

![Codex 扩展详情页](image-8.png)
<p align="center">图 2｜Codex 扩展详情页</p>

### 3. 打开 Codex 侧栏

安装完成后，活动栏会出现 Codex 入口。点击入口打开侧栏，第一次使用时需要先登录。

![打开 Codex 侧栏](image-9.png)
<p align="center">图 3｜打开 Codex 侧栏</p>

### 4. 检查登录页面

如果侧栏没有登录入口，先重新打开登录页面。

如果页面打不开，检查网络或更换节点后再重试。扩展已经安装，并不代表登录服务一定能够正常连接。

网络正常时，侧栏会显示登录界面。

![Codex 登录界面](image-10.png)
<p align="center">图 4｜Codex 登录界面</p>

### 5. 通过 ChatGPT 登录

点击“通过 ChatGPT 登录”，浏览器会打开登录页面。完成登录和授权后，回到 VS Code，侧栏会刷新为已登录状态。

![通过 ChatGPT 登录 Codex](image-11.png)
<p align="center">图 5｜通过 ChatGPT 登录 Codex</p>

> **登录时不要急着关页面**：如果浏览器没有自动切回编辑器，直接返回原来的 VS Code 窗口，重新查看 Codex 侧栏。登录完成前，不要关闭浏览器或编辑器。

### 6. 完成首次设置

按引导点击“下一步”完成设置，随后就可以使用 Codex。

![完成首次设置](image-12.png)
<p align="center">图 6｜完成首次设置</p>

## 二、打开项目并添加上下文

登录后，先在 VS Code 中打开项目文件夹，再打开要处理的文件。

这样添加上下文时，可以直接选择项目中的相关文件。第一次使用时，建议先让 Codex 解释一个函数，或尝试一处小改动，确认流程正常后再处理较大的任务。

### 1. 添加当前文件和参考文件

在 Codex 侧栏中选中当前文件，也可以添加其他参考文件，然后写下任务。

![打开项目和添加文件上下文](image-13.png)
<p align="center">图 7｜打开项目和添加文件上下文</p>

### 2. 从“文件”菜单打开项目

也可以从左上角的“文件”菜单打开项目文件夹。

![从文件菜单打开文件](image-14.png)
<p align="center">图 8｜从“文件”菜单打开项目</p>

> **建议的第一次任务**：先让 Codex 解释一个函数，或完成一个范围很小的修改。确认修改、检查和撤销流程都正常后，再交给它更大的任务。

## 四、常见问题

- **安装后找不到入口**：确认扩展已经安装，再检查活动栏是否被隐藏。重启编辑器也可以让扩展重新加载。
- **没有显示登录页面**：先检查网络和当前节点。页面打不开时，反复点击登录不会解决问题。
- **浏览器登录后编辑器仍未登录**：回到原来的编辑器窗口，重新打开 Codex 侧栏；还是没有变化，就重启编辑器。
- **Codex 看不到项目文件**：确认打开的是项目文件夹，并在请求中添加需要参考的文件或当前文件。

## 小结

安装完成后，先确认登录状态，再打开项目文件夹并添加上下文。第一次使用从小任务开始，确认流程正常后，再逐步扩大任务范围。
