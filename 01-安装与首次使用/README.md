## 按入口阅读

### 使用 Codex App

1. 先看安装路线总览。
2. 根据系统选择 macOS 或 Windows 安装教程。
3. 完成登录、打开本地项目和第一次修改。

### 使用 Codex CLI

1. 先看安装路线总览。
2. 根据系统选择 macOS，或 Windows 与 WSL 安装教程。
3. 完成登录、打开本地项目和第一次修改。

### 使用 IDE

1. 先看安装路线总览。
2. 根据编辑器选择 VS Code 兼容编辑器、Xcode 或 JetBrains 教程。
3. 完成登录、打开项目和第一次修改。

## 阅读目标

读者能够选择适合自己的入口，完成真实安装和登录，知道 Codex 可以访问哪些文件，并完成一个范围明确、可以检查和回退的小任务。
