# 打开练习目录：只读确认两个文件

本课把第 2 课已经登录的那个入口接到同一份静态网页练习。全程使用一个复制出的目录，目录内只需要 `index.html` 和 `styles.css`。

<a id="guide-heading-0"></a>
## 1. 取得并复制练习包

如果你已在第 1 课复制了 `codex-first-task-test/`，直接沿用它，不再复制。搜索直达或尚未准备的读者，下载[本地网页练习包](../练习材料/Codex首次任务-本地网页练习包.zip)，解压后找到 `起始文件/`，复制它到新的测试目录，例如：

```text
codex-first-task-test/
├── index.html
└── styles.css
```

外层练习包还包含任务说明、检查清单和参考差异，它们帮助你了解材料；真正交给 Codex 打开的工作目录就是上面这两个文件。不要直接修改原始 `起始文件/`。

<a id="guide-heading-1"></a>
## 2. 在已经选定的入口打开目录

<a id="guide-heading-2"></a>
### App

在 App 的选择项目文件夹入口中选中 `codex-first-task-test/`。具体按钮以当前客户端为准。先在系统文件管理器中确认该目录直接包含 `index.html` 和 `styles.css`。

<a id="guide-heading-3"></a>
### CLI

先在系统文件管理器中找到副本，查看或复制其完整路径。下方路径是示例，必须替换为你电脑上的真实路径；保留引号以支持空格。macOS/Linux 在终端进入该目录，核对位置和文件后，再启动 Codex：

```bash
cd "/你的实际路径/codex-first-task-test"
pwd
ls
codex
```

Windows PowerShell 可以使用：

```powershell
Set-Location "C:\你的实际路径\codex-first-task-test"
Get-Location
Get-ChildItem
codex
```

如果出现“找不到路径”，先修正路径，不要继续执行 `codex`。列出的文件应直接包含 `index.html` 和 `styles.css`。

<a id="guide-heading-4"></a>
### IDE extension

在编辑器中打开 `codex-first-task-test/` 文件夹，再打开 Codex 侧栏。IDE 是已有编辑器用户的可选入口，不需要为了本课程另外安装 VS Code。

## 3. 发一条只读提示

在 Codex 输入框中发送下面这条提示。它只检查当前位置，不修改文件：

```text
请先只读取当前目录的 index.html 和 styles.css，不修改文件。
告诉我：当前主标题、简介、按钮文字和链接地址分别是什么。
如果缺少任何一个文件，先说明当前目录里有哪些文件，不要创建文件补齐。
不要安装依赖、构建或部署。
```

### 预期输出

Codex 应该能指出：

- 当前主标题是“晨间读书角”；
- 简介是“用十分钟记录今天读到的一段话，慢慢建立自己的阅读清单。”；
- 按钮文字是“查看阅读清单”；
- 链接地址是 `https://example.com`；
- `styles.css` 是当前页面的样式文件。

这些文字来自练习包当前起点。若你的输出不同，先停止，不要创建文件或继续修改；检查是否打开了复制出的目录，以及是否误用了旧副本。

## 4. 文件找不到时

- 先查看当前目录的实际文件列表，确认是不是 `codex-first-task-test/`；
- 不要用 Codex 自动创建缺少的文件；
- 不要把桌面、练习包外层或另一个项目当成工作目录；
- 确认后仍不一致，就重新从原始 `起始文件/` 复制一份。

本课程不要求 `README.md`、`package.json`、`src/`、`tests/`、Git 仓库或 Node.js。那些是其他真实项目可能存在的文件，不能混入这次静态网页练习的前置条件。
