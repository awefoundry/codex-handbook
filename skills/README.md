# 公众号内容工作流 Skills

本目录保存公众号文章从素材准备、文字润色、配图处理到封面规划所需的脱敏 Skill 文档。公众号后台的注册、认证、预览、发布和群发动作不由这些 Skill 自动执行，交接时应由负责人按照实际账号权限完成。

## 核心工作流

| Skill | 用途 | 关键入口 |
|---|---|---|
| `gzhstart` | 创建文章旁的素材备份区，记录环境、来源、截图和人工补拍清单 | `SKILL.md`、`scripts/init_gzh_workspace.py` |
| `gzhwz` | 人性化润色、正文配图处理、图片编号、链接埋点、CTA 和封面确认闸门 | `SKILL.md`、`references/tracking-examples.md` |
| `imagegzh` | 按统一的一号样式整理公众号正文截图 | `SKILL.md` |

## 运行约定

- 安装位置由当前运行环境决定。Skill 之间用 `$skill-name` 或技能名引用，不依赖本机绝对路径。
- 需要登录的平台、浏览器会话、Cookie、API Key、Token、AppSecret、二维码和账号资料只在本地受控环境中使用，禁止写入仓库、文章正文、截图、日志或公开报告。
- `gzhwz/references/historical-article-catalog.md` 在公开版本中保持为空；个人公众号历史文章白名单只保留在受控本地副本。
- 图片素材按文章建立独立工作区。原图、处理中间文件、二维码和封面不要混入正文配图目录。
- 公众号排版使用 [Markdown Nice](https://editor.mdnice.com/)。建议先在本地完成正文、图片路径和敏感信息检查，再粘贴到编辑器中复核标题、图注、段间距、链接和手机端效果。
- 公众号发布、预览、群发和最终确认由负责人手动完成，本仓库只记录可复用的准备与验收方法。

## 脱敏边界

本次同步不包含二维码、图片素材、缓存、编译产物、个人文章目录、账号后台截图、内部图片生成线路实现、密钥或登录配置。相关 Skill 的公开说明可以保留工具名称和通用环境变量名，但不得包含真实值、机器路径、内部服务地址或任务标识。
