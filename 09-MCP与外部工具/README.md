# MCP 与外部工具

讲清楚 Codex 如何连接外部数据和服务，以及连接后产生的权限边界。

## 内容范围

- MCP 的作用和基本工作方式。
- STDIO 与 Streamable HTTP。
- OAuth、Bearer Token 和环境变量。
- 项目级与全局 MCP 配置。
- 工具范围、审批策略和超时设置。
- Notion、GitHub、文档、浏览器等连接实操。
- 连不上、没有工具和认证失败的排查方法。
