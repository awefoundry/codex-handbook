# 插件工作流

介绍如何把 Skills、MCP 和外部工具组合成可安装、可复用的工作流。

## 内容范围

- 插件与 Skill、MCP 的关系。
- 浏览、安装、启用、调用和卸载插件。
- plugin.json 和 marketplace.json。
- 创建本地插件并进行验证。
- 团队分享和版本维护。
- 插件权限、数据共享和风险检查。
