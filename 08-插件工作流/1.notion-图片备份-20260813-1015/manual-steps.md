# 需要作者亲自截图

以下画面涉及账号、工作区权限或第三方授权，必须由作者亲自操作。统一使用无敏感数据的测试 Notion 工作区。

- [ ] `00-environment-versions.png`：分别打开 Windows 系统信息、Codex 桌面端 About/应用信息与 Notion 插件详情；记录正文环境表需要的版本或“未展示版本号”状态；隐藏账号、设备名、工作区和许可证信息。
- [ ] `01-notion-plugin-directory.png`：打开支持插件的 ChatGPT Work 或 Codex 桌面端 -> Plugins -> 搜索 Notion；预期画面为结果列表；隐藏工作区名称、头像及其他已安装插件。
- [ ] `02-notion-plugin-details.png`：Notion 结果 -> 插件详情；预期画面为能力、连接要求和权限说明；停在 Connect 或授权之前。
- [ ] `03-notion-connect-entry.png`：插件详情 -> Connect；只截连接入口，不显示 OAuth 账号、验证码、Cookie 或成员信息；停在跳转授权前。
- [ ] `04-notion-permission-review.png`：进入 Notion 授权页；只截权限范围与目标工作区选择；隐藏邮箱和空间名称；停在最终授权按钮前。
- [ ] `05-notion-installed-state.png`：安装完成后新建任务 -> Sources / Use plugins -> Notion；隐藏历史任务与私人来源。
- [ ] `06-notion-read-example.png`：让插件搜索专用公开测试页面；预期画面为来源调用与读取结果；不得使用真实公司知识库。
- [ ] `07-notion-write-approval.png`：如支持写入，要求更新测试页面；预期画面为写操作审批；停在确认前，不修改真实页面。
- [ ] `08-notion-success-state.png`：在测试工作区完成一次可撤销操作后截图；确认没有客户、项目、成员或内部链接。

不要执行最终发布、付费、删除或不可逆设置变更。连接范围或权限不确定时停止操作并记录界面文字。
