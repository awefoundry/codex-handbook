# 快速上手：完成第一个本地网页任务

这是首期唯一推荐练习。它面向已经安装并登录 Codex App 或 CLI、并能访问练习文件夹的读者。只需选择一种入口；App 与 CLI 使用同一份文件和验收要求。

## 先判断你属于哪种情况

- **尚未准备好**：先看[安装与登录](../01-安装与首次使用/README.md)、[第一次使用前的准备](../00-从这里开始/06-第一次使用前要准备什么.md)，再回来取得练习文件。
- **已经能使用 App 或 CLI**：直接进入[首次任务教程](../00-从这里开始/07-完成第一个真实任务.md)，按“准备 → 打开练习项目 → 完成小修改 → 检查结果”操作。

## 取得练习文件

下载[Codex首次任务-本地网页练习包](../练习材料/Codex首次任务-本地网页练习包.zip)，或复制仓库中的 [`练习材料/首次任务-本地网页/`](../练习材料/首次任务-本地网页/)。解压后先阅读 `README.md`、`任务说明.md` 和 `检查清单.md`，再将其中的 `起始文件/` 复制到新的测试目录。原始 starter 只读保存，完成后重新解压到新目录即可重来。

## 四步主线

1. **准备**：确认已登录一种 Codex 入口，并使用独立、无敏感信息的测试目录。
2. **打开练习项目**：在 App 中打开该目录，或在 CLI 中从该目录启动 Codex。
3. **完成小修改**：让 Codex 只修改 `index.html` 的标题和简介，保留按钮链接、其他内容和样式。
4. **检查结果**：查看 diff，并在浏览器打开 `index.html` 核对实际页面。

完成后继续看[完成第一次修改并检查结果](../01-安装与首次使用/09-完成第一次修改并检查结果.md)。遇到安装、登录或权限问题，进入[故障排查目录](../15-故障排查与常见问题/README.md)。完整文章库仍在各栏目和 [学习路线](../学习路线.md)。
