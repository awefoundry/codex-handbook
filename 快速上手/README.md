# 快速上手：五课完成第一个本地网页任务

这是一条可以连续跟做的短课程。它使用同一份静态 HTML/CSS 练习，从入口准备到结果验收走完五课；App、CLI 和 IDE 只在打开目录的方式上有区别。

## 先按当前状态选择起点

- **还没安装**：从[第 1 课：安装与准备](../00-从这里开始/06-第一次使用前要准备什么.md)开始。
- **已经安装但还没登录**：进入[第 2 课：登录 Codex](../01-安装与首次使用/07-登录Codex.md)。
- **已经安装并登录**：直接进入[第 3 课：打开练习目录](../01-安装与首次使用/08-打开第一个本地项目.md)。
- **已经打开正确的练习目录**：进入[第 4 课：完成第一次修改](../00-从这里开始/07-完成第一个真实任务.md)。
- **已经完成修改**：进入[第 5 课：检查结果](../01-安装与首次使用/09-完成第一次修改并检查结果.md)。

四种入口卡片是按任务访问的入口，不是五课的一对一替代：安装准备、首次练习、完成后的项目实践和问题排查各自服务不同需要。

## 五课顺序

1. [安装与准备：选定一个 Codex 入口](../00-从这里开始/06-第一次使用前要准备什么.md)：选一种入口，准备无敏感信息的练习目录。
2. [登录 Codex 并确认入口可用](../01-安装与首次使用/07-登录Codex.md)：完成认证，区分凭据和文件权限。
3. [打开练习目录：只读确认两个文件](../01-安装与首次使用/08-打开第一个本地项目.md)：让 Codex 读取同一份 `index.html` 和 `styles.css`。
4. [完成第一次网页修改](../00-从这里开始/07-完成第一个真实任务.md)：只修改标题和简介。
5. [检查结果并安全重来](../01-安装与首次使用/09-完成第一次修改并检查结果.md)：对照文件、打开浏览器，并知道如何重新复制起点。

课程顺序只服务这条新手主线，不按照全站文章编号或发布时间排列。已经准备好的人可以跳过前置课，但不要跳过自己尚未满足的条件。

## 取得同一份练习文件

下载[Codex首次任务-本地网页练习包](../练习材料/Codex首次任务-本地网页练习包.zip)，解压后将 `起始文件/` 复制到新的测试目录。真正交给 Codex 修改的目录只需要：

```text
codex-first-task-test/
├── index.html
└── styles.css
```

外层压缩包的 `README.md`、`任务说明.md`、`检查清单.md` 和 `参考差异/` 是材料说明，不是工作目录的必备文件。本课程不会突然要求 Node.js、`src/`、`tests/` 或 Git 仓库。

## 四种任务入口

- **入门准备**：从第 1 课选定入口，再进入登录。
- **首次练习**：从第 3 课打开目录，或直接进入第 4 课开始修改。
- **项目实践**：完成五课后，再阅读[项目理解与上下文](../03-项目理解与上下文/README.md)和[代码修改与开发实战](../04-代码修改与开发实战/README.md)。第 4 课中的历史案例是选读材料，不是第二套必做练习。
- **问题排查**：遇到登录、权限、Git 或验证问题时，查看[故障排查目录](../15-故障排查与常见问题/README.md)。

## 完成后继续

需要按读者目标继续学习时，进入[学习路线](../学习路线.md)或[完整教程目录](https://codexguide.io/guides)。完整文章仍然保留在各栏目中；这页只负责把第一次任务组织成五课主线。
