# 代码修改与开发实战

围绕日常开发任务，展示 Codex 如何修改真实项目，以及人应该检查什么。

## 内容范围

- 增加一个小功能。
- 修复可以复现的 Bug。
- 修改多个相互关联的文件。
- 安装或升级依赖。
- 小范围重构和补充文档。
- 控制修改范围，避免不必要的重写。

实操文章需要提供修改前状态、操作过程、代码差异和验证结果。
