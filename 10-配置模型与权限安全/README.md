# 配置、模型与权限安全

集中说明 Codex 的配置入口、模型选择和执行边界。

## 内容范围

- config.toml 的位置、优先级和常用字段。
- 模型、推理强度、输出详细程度和配置 profile。
- 身份认证和凭据保存方式。
- 沙箱模式、审批策略和目录权限。
- 网络访问、搜索和外部连接。
- Token、密钥和敏感文件保护。
- 个人、项目和团队配置的区别。
