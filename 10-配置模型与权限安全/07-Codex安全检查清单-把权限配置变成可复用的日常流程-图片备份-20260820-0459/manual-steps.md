# 需要作者亲自截图

当前文章不要求登录、注册、支付或发布操作。截图只用于展示本机 Codex 权限面板和版本控制状态；任何含有账号、密钥或客户数据的画面都不要保存。

1. `07-01-start-checklist.png`
   - 起始位置：打开 Codex Desktop 中的临时、无敏感资料的 Git 仓库。
   - 菜单路径：任务输入框下方的权限控件 → 查看当前权限 profile / sandbox；同时保留项目分支状态和模型名称可见。
   - 预期画面：能同时确认仓库或分支、模型、推理强度、profile、sandbox，以及网络是否开启；它证明任务开始前检查已经有固定入口。
   - 隐藏信息：完整本机路径、仓库私有名称、账号头像或邮箱、客户文件名、环境变量值、token、密钥。
   - 停止位置：截图完成后关闭权限菜单，不要点击“Full access”、批准未知命令或执行任务。

2. `07-02-approval-check.png`
   - 起始位置：同一临时仓库中提交一个会触发审批的无害测试请求，例如尝试访问工作区外的空目录；不要使用真实敏感目录。
   - 菜单路径：Codex 审批提示 → 展开完整命令、目标目录和网络说明 → 保持提示停留。
   - 预期画面：能读到完整命令、作用目录、网络行为和一次性/会话级批准范围；它证明执行中人工检查点确实存在。
   - 隐藏信息：用户目录、真实仓库名、账号信息、任何路径中的客户或项目名称；不要把真实密钥放进测试命令。
   - 停止位置：只截图审批提示，选择取消或关闭，不要批准、不要继续执行。

3. `07-03-final-diff-check.png`
   - 起始位置：临时仓库完成一个可回滚的小改动，并运行与文章无关的最小测试。
   - 菜单路径：版本控制面板 → 查看提交前 diff → 打开测试输出或终端摘要；保持未提交状态。
   - 预期画面：能看到改动文件、diff、测试结果和待处理风险，且没有计划外下载或敏感输出；它证明交付前检查不是凭记忆完成的。
   - 隐藏信息：token、`.env` 内容、SSH 密钥、客户数据、私人路径、远程仓库地址和账号信息。
   - 停止位置：截图后不要点击提交、推送、部署、批量删除或发布。
