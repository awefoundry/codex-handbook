# 需要作者亲自截图

将截图放入本工作区的 `manual/` 目录。本文不涉及发布、付款或不可逆设置。

1. [ ] `01-codex-model-control.png`
   - 起点：打开 Codex Windows 桌面端并新建一个空白任务。
   - 路径：任务输入区 → 输入框下方的模型与推理强度控件。
   - 预期画面：控件处于收起状态，能说明模型入口在哪里。
   - 隐藏：账号名、组织名、历史任务标题、真实工作区路径。
   - 停止：不要点击发送，也不要输入私人项目内容。

2. [ ] `02-codex-model-list.png`
   - 起点：仍在空白任务。
   - 路径：输入框下方 → 点击当前模型名称 → 展开模型列表。
   - 预期画面：完整显示当前账号可选模型，证明列表会随产品与账号权限变化。
   - 隐藏：账号、组织和任何私人任务信息。
   - 停止：停在列表展开状态，不必选择模型。

3. [ ] `03-codex-reasoning-levels.png`
   - 起点：仍在空白任务。
   - 路径：输入框下方 → 点击推理强度控件。
   - 预期画面：完整显示当前可见的 Light、Medium、High、Extra High 等档位；若名称不同，保留原始界面并在正文注明版本。
   - 隐藏：账号、组织、任务历史和工作区路径。
   - 停止：停在菜单展开状态，不需要改变默认值。

4. [ ] `04-codex-same-task-comparison.png`
   - 起点：新建三个一次性空白任务。
   - 路径：分别选择本文计划比较的三个档位 → 输入同一条公开、无敏感信息的小任务 → 等待完成。
   - 预期画面：组合展示三个结果，以及界面实际提供的耗时或用量信息；只比较可观察数据，不凭主观印象下绝对结论。
   - 隐藏：账号、组织、额度、私人文件名、仓库路径和通知内容。
   - 停止：结果生成完成即可；不要授权额外工具、打开私人文件或执行外部发布。
