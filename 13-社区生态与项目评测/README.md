# 社区生态与项目评测

收录值得关注的第三方插件、Skills、MCP 和 Codex 周边项目，并记录真实验证结果。

## 收录前检查

1. 仓库是否仍可访问。
2. 最近更新时间和提交活跃度。
3. README、安装方式和许可证是否清楚。
4. 是否需要 Token、OAuth 或高风险权限。
5. 是否有测试、CI 或安全扫描。
6. 能否在本地完成最小验证。
7. 有哪些限制和替代方案。

本栏目不做单纯的链接堆积。无法实操的项目只能作为观察记录，不能写成推荐结论。
