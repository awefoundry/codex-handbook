# 安装与准备：选定一个 Codex 入口

本课只做一件事：选定一个入口，并把它准备到可以进入下一课登录的状态。你不需要同时安装 App、CLI 和 IDE，也不需要先准备 Git、Node.js、MCP 或插件。

<a id="guide-heading-0"></a>
## 本课完成后

你应该已经：

- 选定 App、CLI 或 IDE extension 中的一个入口；
- 知道该入口的官方安装页面；
- 准备好一个无敏感信息、可以重新开始的练习目录；
- 知道下一步是登录，而不是马上修改文件。

<a id="guide-heading-1"></a>
## 先选一个入口

按你平时工作的地方选择一种即可：

| 入口 | 适合谁 | 当前官方入口 |
| --- | --- | --- |
| ChatGPT 桌面应用中的 Codex | 想在桌面窗口管理项目和任务 | [桌面应用说明](https://learn.chatgpt.com/docs/app) |
| Codex CLI | 习惯终端，希望在本地目录中工作 | [Codex CLI Quickstart](https://learn.chatgpt.com/docs/codex/cli) |
| IDE extension | 想在现有编辑器旁边操作 | [Codex IDE extension](https://learn.chatgpt.com/docs/codex/ide) |

第一次只选一个入口。后续可以再比较其他方式，不要为了完成本课把三个入口都装一遍。

<a id="guide-heading-2"></a>
## 按官方步骤安装

<a id="guide-heading-3"></a>
### 使用 Codex CLI（macOS 或 Linux）

OpenAI 当前 CLI Quickstart 提供的独立安装命令是：

```bash
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```

安装后打开一个新的终端窗口，检查版本：

```bash
codex --version
```

输出应包含 Codex CLI 的版本号。这只确认安装可用；认证在第 2 课完成，进入练习目录在第 3 课完成。如果提示找不到命令，先重新打开终端，再按官方安装页检查路径。

Windows、npm 和 Homebrew 的选项会随官方页面一起更新。请直接打开 [Codex CLI Quickstart](https://learn.chatgpt.com/docs/codex/cli)，在页面的安装区域选择当前系统，不要照抄旧版本命令。

<a id="guide-heading-4"></a>
### 使用桌面应用或 IDE extension

分别打开[桌面应用说明](https://learn.chatgpt.com/docs/app)或[IDE extension 说明](https://learn.chatgpt.com/docs/codex/ide)，按页面提供的当前安装入口完成安装。安装按钮、系统要求和可用平台以官方页面为准；本课不猜测具体按钮名称。

<a id="guide-heading-5"></a>
## 准备本课程的练习目录

本课程使用一份已经验证过的静态网页练习。它不需要依赖安装、Node.js、Git 仓库或网络服务。

下载[首期本地网页练习包](../练习材料/Codex首次任务-本地网页练习包.zip)，解压后把 `起始文件/` 复制到一个新的测试目录。真正交给 Codex 打开的工作目录只需要：

```text
codex-first-task-test/
├── index.html
└── styles.css
```

保留原始 `起始文件/` 不动，之后如果需要重来，重新复制一份即可。不要把 Token、`auth.json`、`.env`、客户资料或生产配置放进练习目录。

<a id="guide-heading-6"></a>
## 这一步不要求什么

下面内容对真实项目有用，但不是本课程的前置条件：

- Git 分支、提交和远程仓库；
- `README.md`、`package.json`、`src/` 或 `tests/`；
- Node.js、Python 或其他项目依赖；
- Cloud、MCP、Skills 和插件。

如果你要处理真实项目，可以在完成这五课后再阅读[项目理解与上下文](../03-项目理解与上下文/)和[代码修改与开发实战](../04-代码修改与开发实战/)。

<a id="guide-heading-7"></a>
## 完成检查

- [ ] 我已经选定一个入口，没有为了开始同时安装多个入口。
- [ ] 我能打开对应的官方安装页面，并按当前系统完成安装或确认已安装。
- [ ] 我已经准备好一个独立、无敏感信息的测试目录或练习包。
- [ ] 我保留了未修改的原始起点。

完成后进入[第 2 课：登录 Codex 并确认入口可用](../01-安装与首次使用/07-登录Codex.md)。已经登录的读者可以直接跳到[第 3 课：打开练习目录](../01-安装与首次使用/08-打开第一个本地项目.md)。
