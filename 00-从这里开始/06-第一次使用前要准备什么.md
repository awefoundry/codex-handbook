# 第 1 课：Codex 第一次使用前要准备什么，选定 App、CLI 或 IDE 一个入口并准备练习目录

> 本文在线版：[codexguide.io/guides/di-yi-ci-shi-yong-qian-yao-zhun-bei-shen-me](https://codexguide.io/guides/di-yi-ci-shi-yong-qian-yao-zhun-bei-shen-me)

> 核对依据：2026-11-23 打开的 [Quickstart](https://learn.chatgpt.com/docs/quickstart)、[Codex CLI](https://learn.chatgpt.com/docs/codex/cli)、[ChatGPT desktop app](https://learn.chatgpt.com/docs/app) 和 [Codex IDE extension](https://learn.chatgpt.com/docs/codex/ide)。Linux x64 上用官方安装脚本和 `npm install -g @openai/codex@0.171.0` 分别确认版本，`codex --version` 都是 `codex-cli 0.171.0`。没有打开桌面应用或 IDE，没有登录，没有配图。

<a id="guide-heading-0"></a>

## 本课完成后

你应该已经：

- 选定 ChatGPT 桌面应用、Codex CLI 或 IDE 扩展中的一个入口；
- 按这个入口当前的官方页面完成安装或启用；
- 如果选的是 CLI，在终端里看到 `codex --version` 打印出版本号；
- 准备好一个没有敏感信息、可以重新复制的练习目录；
- 知道下一步是登录，而不是马上改文件。

四个入口怎么取舍，见 [App、CLI、IDE 和 Cloud 怎么选](./05-App-CLI-IDE和Cloud怎么选.md)。本课不把 Cloud 当作练习入口。

<a id="guide-heading-1"></a>

## 先选一个入口

按你平时工作的地方选一个。Quickstart 写：开发者如果要在终端或编辑器里用 Codex，用 Codex CLI 或 IDE 扩展；桌面应用支持 macOS、Windows 和 Linux。

| 入口 | 适合谁 | 当前官方页面 |
| --- | --- | --- |
| ChatGPT 桌面应用里的 Codex | 想在桌面窗口里管理项目和任务 | [桌面应用](https://learn.chatgpt.com/docs/app)。Linux 的安装说明在 [Linux desktop app](https://learn.chatgpt.com/docs/linux/linux-app) |
| Codex CLI | 习惯终端，希望在本地目录里工作 | [Codex CLI](https://learn.chatgpt.com/docs/codex/cli) |
| IDE 扩展 | 已经在 VS Code、Cursor 或 Windsurf 里写代码 | [Codex IDE extension](https://learn.chatgpt.com/docs/codex/ide) |

第一次只选一个。不要为了完成本课把三个都装一遍。装好哪一个，下一课就登录哪一个。更完整的系统差异见 [安装路线总览](../01-安装与首次使用/01-安装路线总览.md)。

<a id="guide-heading-2"></a>

## 按官方方式安装

下面的命令都来自 2026-11-23 的 [Codex CLI](https://learn.chatgpt.com/docs/codex/cli)。页面若改了命令，以页面为准。

<a id="guide-heading-3"></a>

### Codex CLI：macOS 或 Linux

```bash
curl -fsSL https://chatgpt.com/codex/install.sh | sh
```

同一条命令也是页面上的更新方式。装完打开一个新的终端，运行：

```bash
codex --version
```

2026-11-23 在 Linux x64 上执行了这个脚本。为了不覆盖这台机器上已经用 npm 装好的 Codex，测试时把 `HOME` 指到一个空目录，并按脚本自己的 `--help` 设置了 `CODEX_NON_INTERACTIVE=true`。脚本打印：

```text
==> Installing Codex CLI
==> Detected platform: Linux (x64)
==> Resolved version: 0.171.0
==> Detected existing npm-managed Codex at ~/.local/bin/codex
WARNING: Multiple managed Codex installs can be ambiguous because PATH order decides which one runs.
==> Downloading Codex CLI
==> Installing standalone package to $HOME/.codex/packages/standalone/releases/0.171.0-x86_64-unknown-linux-musl
WARNING: Leaving the existing npm-managed Codex installed. PATH order will determine which codex runs.
==> Current terminal: export PATH="$HOME/.local/bin:$PATH" && codex
==> Future terminals: open a new terminal and run: codex
==> PATH was added to $HOME/.bashrc
Codex CLI 0.171.0 installed successfully.
```

上面把本机用户目录换成了 `~` 和 `$HOME`。`PATH was added to $HOME/.bashrc` 写的是这次测试用的空 `HOME`，不是读者自己的启动文件。随后那个独立目录里的 `codex --version` 输出：

```text
codex-cli 0.171.0
```

脚本发现 PATH 上已经有一份 npm 安装时，会警告两份安装可能分不清，并保留原来的那一份。日常只需要一种安装方式。页面上的命令不要求你设置 `HOME` 或 `CODEX_NON_INTERACTIVE`。

打开 `https://chatgpt.com/codex/install.sh` 时，请求会转到 `https://releases.openai.com/codex/install.sh`。教程里仍写页面上的那条 `curl`。

### Codex CLI：Windows

官方页面写从新的 PowerShell 窗口运行：

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
```

更新用的是同一条命令。本文的环境是 Linux，没有执行 `install.ps1`。

### Codex CLI：npm

官方页面还有：

```bash
npm install -g @openai/codex
```

更新是再执行一次同一条命令。这条需要本机已经有 Node.js 和 npm。2026-11-23 执行的是 `npm install -g @openai/codex@0.171.0`，`codex --version` 同样是 `codex-cli 0.171.0`。npm 上当天的 `latest` 也是 0.171.0。本课不要求为了练习去锁版本；页面上的命令没有写 `@0.171.0`。

### Codex CLI：Homebrew

官方页面还有 macOS 上的：

```bash
brew install --cask codex
```

更新是 `brew upgrade --cask codex`。写作环境不是 macOS，没有执行 Homebrew。

<a id="guide-heading-4"></a>

### 桌面应用或 IDE 扩展

桌面应用按 [Quickstart](https://learn.chatgpt.com/docs/quickstart) 和 [桌面应用说明](https://learn.chatgpt.com/docs/app) 安装。Quickstart 写 ChatGPT 桌面应用可用于 macOS、Windows 和 Linux，并要你按操作系统选择版本。Linux 的包和发行版见 [Linux desktop app](https://learn.chatgpt.com/docs/linux/linux-app)。本文没有打开桌面应用，不描述按钮上的文字。

IDE 按 [Codex IDE extension](https://learn.chatgpt.com/docs/codex/ide)。2026-11-23 这一页写：VS Code 和兼容编辑器使用 Codex 扩展，Xcode 和 JetBrains 有各自的集成。VS Code、Cursor、Windsurf 的安装入口都指向扩展 `openai.chatgpt`。打开方式那一节写：选择 Codex 图标；如果看不到，打开命令面板，运行 **Codex: Open Codex Sidebar**。Xcode 是在编码助手的新对话里选择 Codex 作为代理。JetBrains 是打开 AI Chat 再选择 Codex。这些是文档里的英文界面名。本文没有打开这些编辑器。

已经装过 IDE 扩展的读者，直接进入下一课登录，不必再装 CLI。

<a id="guide-heading-5"></a>

## 准备练习目录

本课程使用一份静态网页练习。它不需要安装依赖、Node.js、Git 仓库或网络服务。

下载[首期本地网页练习包](../练习材料/Codex首次任务-本地网页练习包.zip)，解压后把 `起始文件/` 复制到一个新的测试目录。真正交给 Codex 打开的工作目录只需要：

```text
codex-first-task-test/
├── index.html
└── styles.css
```

保留原始 `起始文件/` 不动。需要重来时，重新复制一份。不要把 Token、`auth.json`、`.env`、客户资料或生产配置放进练习目录。

打开这个目录是第 3 课的事。本课只把它准备好。

<a id="guide-heading-6"></a>

## 这一步不要求什么

下面这些对真实项目有用，但不是这五课的前置条件：

- Git 分支、提交和远程仓库；
- `README.md`、`package.json`、`src/` 或 `tests/`；
- Node.js、Python 或其他项目依赖（只有你选择用 npm 安装 CLI 时，才需要 Node.js 和 npm）；
- Cloud、MCP、Skills 和插件。

真实项目留到五课之后，再读[项目理解与上下文](../03-项目理解与上下文/)和[代码修改与开发实战](../04-代码修改与开发实战/)。
