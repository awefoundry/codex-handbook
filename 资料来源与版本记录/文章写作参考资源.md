# 文章写作参考资源

这份文档是后续编写、补充和修订 Codex 教程时使用的长期参考索引。它只保存必要摘要和选题价值，不复制外部文章全文。

最后整理日期：2026-08-06（北京时间）。

## 使用原则

1. OpenAI 官方文档、官方仓库和官方课程是产品事实的首要依据。
2. 社区教程主要用于参考选题、结构、案例和讲解方式，不能单独证明 Codex 的当前功能。
3. 模型名称、价格、套餐、安装命令、配置字段、功能状态和平台支持范围都属于高时效信息，写入正文前必须重新核对官方资料。
4. 引用外部观点、图表、截图或示例时，应在文章末尾保留原始链接，并遵守原作者的版权和许可证要求。
5. 对未经本地实操验证的步骤，应明确标记为“待验证”，不能写成已经验证的结论。

### 官方来源使用顺序

1. 先查看 Codex 官方文档中的对应主题页面。
2. 涉及 CLI 行为、命令和版本问题时，再核对 `openai/codex` 仓库、发布记录和 Issue。
3. 需要实操过程和教学表达时，参考 OpenAI Academy 或官方视频。
4. 如果不同官方页面存在差异，在正文中注明页面、核对日期和适用版本，不自行猜测。

## 当前手册建设提示

- 优先补全 Windows App、Windows/WSL CLI、登录排障和首次本地项目。
- 用一个标准任务串联调查、计划、修改、测试、Review 和 Git 提交。
- 在基础教程中讲清 Prompt、上下文、AGENTS.md、完成标准、沙箱和审批。
- Skills、MCP、Plugins 各提供一个可以复现的最小案例。
- Worktree、多 Agent、定时任务、Hooks、SDK 和 App Server 放在基础闭环之后。
- 中文教程的差异化重点是 Windows 实操、真实截图、失败案例、验证证据和明确的版本日期。
