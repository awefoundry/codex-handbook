# 图解与速查

把已经在正文中验证过的概念、步骤和判断整理成便于查阅的图表。

## 内容范围

- App、CLI、IDE 和 Cloud 对比。
- Skill、Plugin、MCP、AGENTS.md 关系图。
- 权限、沙箱和审批模式速查。
- config.toml 常用配置说明。
- 任务开始前、修改后和发布前检查表。
- 常见命令、目录位置和故障排查流程图。

速查内容必须能回链到详细文章或官方来源，不能脱离依据单独给结论。
